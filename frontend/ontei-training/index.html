音程（インターバル）トレーニング

音程（おんてい）とは、2つの音の高さの距離のことです。英語ではインターバル（interval）と呼びます。音程を聴き分けられるようになると、メロディーを聴いて楽譜に書いたり、耳で聴いた曲を楽器で弾いたりするのがぐっと楽になります。聴音・耳コピ・ハモリのどれにも役立つ、いちばん基本の力です。

その場で練習：音程の聴き分け

主な音程と半音の数

音程半音の数例（下の音がドのとき）響きの特徴

長2度2ド → レ音階を一歩進む距離
短3度3ド → ミ♭少し暗く、やわらかい
長3度4ド → ミ明るく、あたたかい

長7度11ド → シ鋭く、オクターブの一歩手前
オクターブ12ド → 上のド同じ音名で、ほぼ溶け合う

練習の方法

  1. 少ない種類から始める。最初は「長3度・完全5度・オクターブ」のように響きの違う音程だけを選び、慣れたら少しずつ増やしましょう。
  2. 上行・下行・同時を練習する。2つの音を順番に聴く（旋律的音程）のと、同時に聴く（和声的音程）のとでは、聴こえ方が違います。
  3. 歌って確かめる。下の音を聴いたら、上の音を自分で歌ってみてから答えを確認すると、耳と声がつながります。
  4. 毎日少しずつ。1日5〜10分でも、続けることで判断がどんどん速くなります。

アプリの「トレーナー」では、12種類すべての音程を、上行・同時、音域、音の長さを選んで練習できます。
